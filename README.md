# Frontend

React, TypeScript, Vite, Tailwind, shadcn/ui e React Router.

## Requisitos

Node **20.19+** (ou 22.12+). Com [nvm](https://github.com/nvm-sh/nvm): `nvm install && nvm use`.

## Comandos

```bash
npm install
npm run dev    # http://localhost:5173
npm run build
```

Makefile: `make front-install`, `make front-run`, `make front-build`.

## Pastas úteis

- `src/pages/` — páginas
- `src/components/ui/` — shadcn
- `src/App.tsx` — rotas (`/` → Home)
